# SWYNEX Python CLI Task Manager

A beginner-friendly command-line task manager built using Python as part of SWYNEX Internship Task 1.

## Features
- Add new tasks
- View saved tasks
- Mark tasks as completed
- Delete tasks
- Save task data using JSON

## Technologies Used
- Python
- JSON
- pathlib

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python task_manager.py
```

## Learning Outcomes
Practiced Python functions, file handling, JSON data storage, input validation, and exception handling.
